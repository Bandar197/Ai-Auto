# بلوت المجلس

لعبة بلوت سعودية كاملة تشتغل في المتصفح: أنت وخويك فهد ضد أبو سعد ومشعل (بوتات).

## التشغيل
افتح `index.html` في أي متصفح. ما تحتاج سيرفر ولا تثبيت.

## المزايا
- قوانين البلوت كاملة: صن، حكم (الدور الأول والثاني)، أشكل، دبل ×2، الصن يغلب الحكم.
- المشاريع: سرا، خمسين، مية، أربعمية، وبلوت (الشايب والبنت من الحكم)، ويحسب مشروع الفريق الأعلى فقط.
- الحساب: الأبناط، الأرض (آخر أكلة +10)، الكبوت (صن 44 / حكم 25)، وخسارة المشتري.
- الإلزام بالقوانين: لازم تنزل من النوع، الدق بالحكم، والتكبير على الحكم.
- بوتات بثلاث مستويات (سهل / متوسط / محترف). المحترف يتذكر الورق ويعرف مين قطع أي نوع.
- تلميح من لاعب محترف في الشراء واللعب (زر "تلميح" أو حرف H).
- عداد الورق: يبين الورق اللي نزل واللي باقي.
- آخر أكلة، وسجل الصكة، وإحصائياتك محفوظة في المتصفح.
- سرعة اللعب، الأصوات، ونهاية الصكة (101 / 152 / 202).
- تصميم يناسب الجوال والكمبيوتر.

## الملفات
- `src/baloot.html`: مصدر اللعبة.
- `index.html`: النسخة الجاهزة للتشغيل، تتولد بالأمر `./build.sh`.
