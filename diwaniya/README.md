# ديوانية — منصة بلوت عربية

الرابط المنشور: **https://bandar197.github.io**

منصة بلوت أونلاين باللغة العربية: حسابات حقيقية، بروفايلات، أصدقاء، غرف لأربعة لاعبين، لعب يحكمه الخادم، تصنيف وخبرة وإنجازات، تدريب ضد البوتات، سجل مباريات وإعادة، ولوحة إدارة.

## البنية

| الجزء | المكان | الدور |
|---|---|---|
| محرك القواعد | `engine/engine.js` | قواعد البلوت كاملة، بدون واجهة أو تخزين. نسخ مطابقة في `web/js/engine.js` و`supabase/functions/api/engine.js`. |
| الواجهة | `web/` | تطبيق صفحة واحدة بـ ES modules بدون خطوة بناء. RTL، متجاوب، يدعم تقليل الحركة. |
| خادم المباريات | `supabase/functions/api/index.ts` | Edge Function هي الكاتب الوحيد للغرف والأيدي المخفية والنتائج. |
| قاعدة البيانات | `supabase/migrations/*.sql` | الجداول، سياسات RLS، دوال RPC الآمنة، البيانات الأولية. |
| المصادقة | Supabase Auth | بريد وكلمة مرور مع تأكيد البريد واستعادة كلمة المرور، وGoogle عند تفعيله. |
| التحديثات الحية | Supabase Realtime | تغييرات الغرفة واليد والدردشة والتنبيهات، والحضور (presence). |
| الصور | Supabase Storage (`avatars`) | حد ١ ميغابايت، webp/png/jpeg فقط، كل مستخدم يكتب في مجلده فقط. |
| المهام المجدولة | pg_cron + pg_net | كل دقيقة: فرض المهلات، إغلاق الغرف المهجورة، مطابقة الطابور. |

## التشغيل محلياً

```bash
# اختبارات المحرك (٢٦ اختباراً)
node --test diwaniya/tests/*.test.mjs

# تشغيل الواجهة محلياً (أي خادم ملفات ثابتة مع إعادة التوجيه لـ index.html)
npx http-server diwaniya/web -p 8080 --proxy http://localhost:8080?
```

انسخ `web/js/config.example.js` إلى `web/js/config.js` وضع رابط مشروع Supabase والمفتاح العام (publishable). لا تضع مفتاح service-role في الواجهة أبداً.
