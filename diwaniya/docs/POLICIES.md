# السياسات

## الوقت والانقطاع والانسحاب (تُعرض للاعب قبل اللعب التنافسي)

| الحالة | ما يحدث |
|---|---|
| وقت الدور | ٣٠ ثانية افتراضياً (٢٠/٣٠/٤٥/٦٠ في الغرف الخاصة)، تبدأ بعد عرض الحركات الأخيرة (+٠٫٧٥ ثانية لكل حركة جديدة، بحد ٢٤). الوقت يحسبه الخادم ويرسله للمتصفح. |
| انتهاء الوقت | الخادم يلعب عن اللاعب ورقة قانونية. |
| ٣ مهلات متتالية | انسحاب: بوت يكمل مكانه. |
| انقطاع الاتصال | بدون نبضة لمدة ٦٠ ثانية = غير متصل. لديه ٣ دقائق ليعود لنفس كرسيه وورقه (تحديث الصفحة أو فتح الرابط). |
| غياب أكثر من ٣ دقائق أو الخروج أثناء اللعب | انسحاب: بوت يكمل، المباراة تُحسب له خسارة، وفي المصنّف خصم ١٥ نقطة إضافية. |
| خسارة الفريق بسبب انسحاب الخوي | خسارة الخوي في التصنيف تنقص للنصف. |
| غياب الأربعة | تُغلق المباراة كـ«متروكة» وتُحسب خسارة للجميع بدون خبرة. |
| حفظ النتيجة | مرة واحدة فقط (`G.recorded` + `matches.status` + `finalize_match` لا تُعاد). |

## الطلبات والتزامن

- كل حركة تحمل `rid` فريداً: الخادم يتجاهل الطلب المكرر (`duplicate: true`).
- كل حركة تحمل `reqId`: الحركة المتأخرة عن دورها تُرفض كـ`stale` بدون أثر.
- الكتابة بقفل تفاؤلي (`rooms.version` + `save_room`)، مع إعادة المحاولة حتى ٦ مرات. لا يمكن تجاوز ٤ مقاعد ولا شغل حساب واحد لمقعدين.

## الدردشة

- أنماط الغرفة: مفتوحة، عبارات سريعة فقط، مقفلة. تُحدد قبل البداية.
- حد الإغراق: ٤ رسائل كل ١٠ ثوانٍ و٢٠ رسالة في الدقيقة لكل لاعب (`send_chat`)، والنص بحد ٢٠٠ حرف، ويُعرض كنص فقط (لا HTML).
- كتم لاعب يخفي رسائله عندك فقط. الحظر يمنع الطلبات والدعوات بين الطرفين.
- الإبلاغ عن رسالة أو لاعب يُحفظ في `reports` مع نص الرسالة وقت البلاغ، ويراجعه المشرفون.
- الرسائل تُحفظ مع الغرفة لأغراض المراجعة وحل النزاعات.

## الخصوصية

- بيانات الحساب الخاصة (البريد، الحظر، آخر ظهور، الإعدادات) في `account_private` ولا يقرؤها إلا صاحبها والخادم.
- لكل لاعب إعداد لظهور حالة الاتصال وسجل المباريات (الكل / الأصدقاء / لا أحد)، ولمن يرسل طلبات الصداقة (الكل / لا أحد) والدعوات (الكل / الأصدقاء / لا أحد).
- أوراق اللاعب في `room_hands` بسياسة RLS تسمح لصاحب المقعد فقط. الأيدي الكاملة تُكشف في الإعادة بعد نهاية المباراة فقط.

## المساعدة أثناء اللعب

التلميحات واقتراح الورقة مع السبب وعداد الأوراق متاحة في التدريب فقط. في الغرف البشرية يُتاح ملف القواعد وآخر أكلة فقط.

## التصنيف والخبرة

- Elo بمعامل K=32 بين متوسط الفريقين، للمصنّف فقط. البداية ١٠٠٠.
- الخبرة: ٣٠ للمشاركة + ٢٠ للفوز + ١٠ لكل كبوت، والإنجازات والتحديات تضيف خبرتها. المستوى n يحتاج 50·n·(n−1) خبرة.
- منع الاستغلال: النتيجة تُعتمد مرة واحدة على الخادم، والمطابقة المصنّفة عشوائية حسب المستوى (لا يمكن اختيار الخصوم)، والغرف الخاصة لا تؤثر على التصنيف.
