# تقرير التسليم

## منفّذ ويعمل

- **الحسابات**: تسجيل بالبريد وكلمة المرور مع تأكيد البريد، دخول وخروج، استعادة كلمة المرور، جلسة مستمرة تتجدد تلقائياً، خروج من الأجهزة الأخرى، رسائل أخطاء عربية، مهلة بعد المحاولات الفاشلة. Google جاهز ويظهر عند تفعيله.
- **الإعداد الأول**: اسم المستخدم (مع فحص التوفر)، الاسم الظاهر، الصورة مع القص.
- **البروفايل** `/u/username`: صورة، اسم، معرف لاعب ثابت، نبذة، تاريخ الانضمام، حالة الاتصال حسب الخصوصية، المستوى والخبرة، الرتبة والتصنيف، الإنجازات، الإحصائيات (صن وحكم وسلسلة)، سجل المباريات، إضافة/دعوة/حظر/إبلاغ.
- **الإعدادات**: الملف، الحساب والأمان (تغيير البريد وكلمة المرور، الخروج من الأجهزة الأخرى)، الخصوصية، المحظورون، التنبيهات، التخصيص (لون الطاولة، ظهر الورق، الإطار)، حذف الحساب بتأكيد.
- **الأصدقاء**: بحث بالاسم أو رقم اللاعب، طلبات (إرسال/قبول/رفض/إلغاء)، إزالة، المتصلون، دعوة لغرفة، تنبيهات حية.
- **الرئيسية**: ملخص الحساب، العب الآن، تنافسي/ودي، غرفة خاصة، انضمام بكود، الغرف العامة، الأصدقاء المتصلون، الدعوات، آخر النتائج، التحديات، أرقام حقيقية مع حالات فارغة.
- **الغرف**: خاصة وعامة، ٤ مقاعد مع اختيار المقعد، استعداد، صلاحيات المالك (طرد، نقل الملكية، تعديل القواعد، البدء، الإنهاء)، نقل الملكية تلقائياً عند خروج المالك، حماية التزامن.
- **اللعب**: الخادم يوزع ويحتفظ بالأيدي ويتحقق من كل حركة ويحسب النتيجة. الطلب المكرر لا يُنفذ مرتين. استعادة الحالة بعد التحديث.
- **محرك القواعد** مستقل وموثق (`docs/RULES.md`) مع إعدادات المجالس، و٢٦ اختباراً.
- **الطاولة**: أوراق واضحة (ومع خيار ٤ ألوان)، صور وأسماء ورتب، الدور والعداد، الموزع والمشتري والخوي، الحكم، الأكلات، القيد، المشاريع، ملخص كل توزيعة، شاشة النهاية، أصوات قابلة للكتم، تقليل الحركة، لوحة المفاتيح.
- **الانقطاع**: سياسة معلنة ومنفذة (انظر POLICIES.md)، مع مهمة مجدولة كل دقيقة.
- **الدردشة**: نصية وعبارات سريعة وإيموجي، كتم، إبلاغ، حد إغراق، أنماط حسب الغرفة.
- **المنافسة**: Elo، مطابقة بالمستوى مع توسيع تدريجي، فصل الودي عن المصنف، لوحة صدارة عامة وللموسم وللأصدقاء، مواسم، سجل تغيّر التصنيف.
- **الخبرة والإنجازات**: مستويات، إنجازات مرتبطة بأحداث فعلية، تحديات يومية وأسبوعية، مكافآت تجميلية مرتبطة بالحساب.
- **التدريب**: شرح تفاعلي، أمثلة، بوتات بثلاث مستويات، اقتراح ورقة مع السبب، سيناريوهات، مراجعة القرارات.
- **سجل المباريات والإعادة**: المشاركون، القواعد، الأوقات، نتيجة كل توزيعة، تغير التصنيف والخبرة، إعادة الحركات، والأيدي الكاملة بعد النهاية فقط.
- **الإدارة**: أدوار (مالك/مدير/مشرف)، اللاعبون والبلاغات، حظر مؤقت ودائم مع السبب، الغرف المتوقفة، المواسم والتحديات، أخطاء الخادم، مؤشرات حقيقية، سجل تدقيق. المالك يُحدد من إعداد على الخادم.

## قيود متبقية

1. **المحادثة الصوتية غير مضمّنة**: تحتاج خدمة صوت فعلية (مثل LiveKit أو Agora) بحساب ومفاتيح. أُبقيت خارج الواجهة حسب طلبك حتى تكتمل.
2. **رسائل البريد**: تأكيد البريد والاستعادة يعملان، لكن وصولها للاعبين يحتاج ربط SMTP في Supabase (خطوة واحدة في اللوحة).
3. **إدارة الجلسات**: المتاح «تسجيل الخروج من كل الأجهزة الأخرى». قائمة تفصيلية بالأجهزة غير متاحة من Supabase للمتصفح.
4. **إصلاح صغير في الخادم بانتظار النشر**: رفض معرّفات اللاعبين غير الصالحة في الحظر وإلغائه وإزالة الصديق. الكود في المستودع، ونشره بأمر واحد: `supabase functions deploy api --no-verify-jwt`. الواجهة الحالية ترسل معرفات صحيحة دائماً، فلا أثر على المستخدمين.
5. حسابات الاختبار الأربعة (أسماؤها تبدأ بـ `e2e_`) ما زالت في الإنتاج وقد تظهر في البحث ولوحة الصدارة حتى تُحذف؛ طريقة حذفها في TESTING.md.
