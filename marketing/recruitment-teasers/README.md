فيلمان إعلانيان عموديان 9:16 (72 ثانية لكل فيلم، 60 إطارا/ث) لمنصة توظيف سعودية تعتمد على الذكاء الاصطناعي.
**لا يظهر اسم المنصة ولا شعارها ولا رابطها في أي إطار** — كل الواجهات والأسماء عامة، وكل الأرقام معلمة «مثال توضيحي».

| الملف | الوصف |
|---|---|
| `out/final/01-job-seeker-teaser-*.mp4` | الفيلم الأول: الباحث عن عمل — «قدمت.. وبعدين؟» |
| `out/final/02-employer-teaser-*.mp4` | الفيلم الثاني: المنشآت ومسؤولو التوظيف — «التوظيف ما لازم يكون بهذه الصعوبة!» |

لكل فيلم ثلاث نسخ: `4K-2160x3840-60fps` (الماستر)، `1080x1920-60fps` (للنشر)، `1080x1920-captions` (للمشاهدة بدون صوت: نص التعليق محروق على الصورة).

## كيف صُنعت

الفيلم كله **كود**: مشاهد HTML/SVG/Canvas بعمق ثلاثي الأبعاد حقيقي (CSS 3D + إسقاط منظوري يدوي)، يقودها خط زمني حتمي
(`seek(t)` يرسم الإطار المطابق للزمن `t` بالضبط)، ثم يُلتقط كل إطار بمتصفح Chromium ويُرمّز بـ x264.
الموسيقى والمؤثرات **مولدة برمجيا** (`audio/mix.py`) فهي أصلية وبلا حقوق طرف ثالث، وكل نقرة و Whoosh و Impact
مربوطة بزمن الحركة نفسها عبر `cue()` داخل كود المشهد — فالتزامن بين الصوت والصورة دقيق بالإطار.

```
src/engine.js        المحرك: الخط الزمني، الكاميرا، الجسيمات، الوميض، الترجمة
src/character.js     الشخصيات (2.5D): تعابير الوجه، الرمش، التفات الرأس، التنفس
src/ui.js            عناصر الواجهة (بطاقات، حلقات المطابقة، السيرة، النوافذ…)
src/video-seeker.js  مشاهد الفيلم الأول      src/video-employer.js  مشاهد الفيلم الثاني
audio/vo.py          توليد التعليق الصوتي      audio/mix.py           الموسيقى + المؤثرات + المكساج
render/render.mjs    التصيير المتوازي          render/build.sh        البناء الكامل لفيلم واحد
```

### إعادة البناء

```bash
npm install                                   # الخطوط + GSAP (مرة واحدة)
python3 audio/vo.py                           # اختياري: إعادة توليد التعليق (يتطلب pip install edge-tts واتصالا بالخدمة)
render/build.sh seeker   01-job-seeker-teaser # ≈ 45 دقيقة على 4 أنوية
render/build.sh employer 02-employer-teaser
```

معاينة حية في المتصفح: افتح `src/player.html?v=seeker&play=1` (أو `v=employer`، وأضف `&cc=1` للترجمة) ثم انقر للتشغيل.
لقطات فحص سريعة: `render/sheet.sh seeker 0,5,10,20 4`.

### استبدال التعليق الصوتي بصوت معلق حقيقي (موصى به قبل النشر)

التعليق الحالي **مسار إرشادي** مولد آليا بصوت سعودي (`ar-SA-HamedNeural`). لاستبداله:
سجل كل سطر في ملف WAV (48kHz) بنفس الاسم داخل `vo/seeker/` أو `vo/employer/` (`a1.wav`, `b1.wav`…)، وحدث أزمنة
الكلمات في ملف `.json` المجاور (بداية كل كلمة ومدتها بالثواني)، ثم شغل `python3 audio/mix.py <film>` وأعد الدمج بـ `render/build.sh`
(لن يُعاد تصيير الصورة ما دامت ملفات `.video.mp4` موجودة). مواضع الجمل على الخط الزمني معرفة في `window.VO` آخر كل ملف فيديو.

## حدود يجب معرفتها

- الشخصيات 2.5D متجهة (Vector) بتعابير ورمش والتفات، وليست شخصيات CGI ثلاثية الأبعاد بمستوى استوديو.
- التعليق مولد آليا بلهجة قريبة من البيضاء السعودية؛ يُنصح بمعلق سعودي حقيقي للنسخة المنشورة (الخطوات أعلاه).
- الموسيقى مركبة برمجيا؛ يمكن استبدالها بمقطوعة مرخصة مع إبقاء المؤثرات (المسارات المنفصلة في `out/tmp/*-music|sfx|vo.wav`).
