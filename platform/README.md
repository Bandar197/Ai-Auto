# بلوت المجلس — المنصة

منصة بلوت سعودي أونلاين: حسابات، لوبي، طاولات عامة وخاصة، دردشة، ترتيب اللاعبين، ولعب ضد البوتات.

## المكونات
| المجلد | وش فيه |
|---|---|
| `site/` | الموقع (HTML/CSS/JS بدون بناء). ينرفع على GitHub Pages. |
| `shared/engine.js` | قوانين اللعبة والبوتات. نفس الملف يشتغل في السيرفر وفي المتصفح. |
| `supabase/functions/game/` | سيرفر اللعبة (Supabase Edge Function). هو اللي يوزع الورق ويتحقق من كل حركة. |

بعد أي تعديل على `shared/engine.js` شغّل `./build.sh` عشان ينسخه للموقع وللسيرفر.

## كيف يشتغل
- **التسجيل**: اسم مستخدم وكلمة مرور فقط. السيرفر ينشئ الحساب (بدون إيميل).
- **السيرفر هو الحكم**: الورق محفوظ في جدول `game_secrets` اللي ما يقدر أحد يقراه غير السيرفر. كل لاعب يشوف ورقه بس (جدول `hands` مع RLS).
- **التحديثات المباشرة**: الموقع يشترك في تغييرات الطاولة عبر Supabase Realtime، ويعيد التحميل كل ٨ ثواني احتياط.
- **الوقت**: ٣٥ ثانية لكل حركة. إذا خلص الوقت، أي جهاز على الطاولة يطلب `tick` والسيرفر يلعب عن المتأخر. بعد مرتين يصير الكرسي بوت لين يرجع اللاعب.
- **التقييم**: يبدأ ١٠٠٠. الفوز +٢٥ والخسارة −١٥، بشرط يكون فيه لاعب حقيقي في كل فريق.

## Supabase
- المشروع: `baloot-majlis` (`kdjexepmmkilhkjqflau`).
- الجداول: `profiles`, `game_tables`, `game_secrets`, `hands`, `messages`, `match_results`.
- الدوال: `save_game` (حفظ ذري مع رقم نسخة)، `record_match` (النتائج والتقييم).

## النشر
الـ workflow في `.github/workflows/pages.yml` ينشر مجلد `site/` على GitHub Pages مع كل push على `main`.
